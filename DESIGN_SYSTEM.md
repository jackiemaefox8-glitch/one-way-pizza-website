# Design System — One Way Pizza

## Brand personality
Bold, appetizing, energetic, premium, welcoming.

## Palette
- Primary background: `#000000`
- Accent gold: `#FFC200` (approximate reference colour; tune against supplied logo)
- Primary text on dark: `#FFFFFF`
- Secondary surface: near-black/charcoal, used only where needed
- Optional green: use sparingly for tiny brand highlights only

The core system should remain disciplined and avoid adding many competing colours. Verify contrast for all text and interactive states.

## Typography
- Use no more than two primary font families.
- Choose a confident display face for headings and a highly readable sans-serif for body/UI.
- Use responsive type scales with comfortable line height.
- Avoid tiny text, overlong line lengths and excessive all-caps.

## Layout
- Mobile-first.
- Consistent spacing scale based on 4/8px increments.
- Clear content hierarchy and generous section spacing.
- Strong hero composition with food photography.
- Reusable cards and buttons.
- Avoid excessive rounded cards, gradients, glow effects and glassmorphism.

## Buttons
- Primary: gold background, dark text, clear hover/focus state.
- Secondary: dark/transparent background with clear border or white text.
- Every button must have a real destination/action.
- Tap targets should be comfortable on touch screens.

## Imagery
- Use supplied brand assets first.
- Do not distort the logo.
- Use licensed/permitted food images; avoid hotlinking unstable image URLs.
- Compress and size images appropriately.
- Add descriptive alt text; decorative images should have empty alt text.

## Accessibility
- Semantic landmarks and headings
- Visible keyboard focus
- Accessible form labels and error messages
- WCAG AA contrast target
- Reduced-motion support
- No information conveyed by colour alone
