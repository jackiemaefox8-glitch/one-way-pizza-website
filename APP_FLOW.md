# App Flow — One Way Pizza

## Journey 1: Find a pizza
Home → Featured Menu → Menu/Deals → Foodpanda listing or call to confirm/order.

## Journey 2: Call the restaurant
Home → Call to Order → Device opens dialler with a supplied phone number.

## Journey 3: Find the location
Home → Contact/Location → Address and Maps link → Google Maps opens.

## Journey 4: Send an inquiry
Home → Contact form → Validate required fields → Submit only if a real endpoint is configured → Show truthful success/error state.

If no endpoint exists, show a clear demo limitation and provide telephone/Foodpanda alternatives.

## Journey 5: Mobile navigation
Open menu → choose section → navigate to target → menu closes accessibly.

## Rules
- Do not simulate checkout or payment.
- Do not imply real-time order tracking.
- Do not show “Open now” until hours are verified.
- Avoid fake success states.
